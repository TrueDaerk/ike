# Guides

Task-oriented pages, one per feature area.

!!! info "This section is being written"
    Progress is tracked in
    [Epic 0440](https://github.com/TrueDaerk/ike/issues/1182).

Planned pages:

- **Search** — in-buffer search, find in path, replace, and the `rg` backend.
- **Code intelligence** — diagnostics, completion, hover, go-to-definition, find usages, rename, and call hierarchy; which language servers IKE looks for.
- **The integrated terminal** — spawning a shell in a pane, how keys are routed, and how to get back to the IDE.
- **Git** — status colours in the explorer, gutter markers, diffs, hunk and file revert, inline blame, and delegating the rest to a tool pane.
- **Running and debugging** — run configurations and the debugger.
- **Themes** — the built-ins, switching live, and where plugin themes come from.
- **Settings** — the settings panel, the TOML layers, and the keys worth knowing.
- **Keybindings** — customising chords, importing a JetBrains keymap, contexts and conflicts.
- **Plugins** — the marketplace, WASM plugins, and what a plugin can add.
- **Scratch files and snippets** — throwaway buffers and live templates.
